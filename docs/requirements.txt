================================================================================
EDUCONNECT — LEARNING MANAGEMENT SYSTEM
SOFTWARE REQUIREMENTS SPECIFICATION
================================================================================

1. OVERVIEW
--------------------------------------------------------------------------------
EduConnect is a Learning Management System (LMS) for managing classes,
curriculum, question banks, assignments, submissions, and student progress.

1.1 STAKEHOLDERS
  - Admin    : Manage all users, classes, system-wide settings
  - Teacher  : Create curriculum, questions, assignments, grade
  - Student  : Enroll classes, do assignments, view progress

1.2 TECH STACK
  - Backend  : NestJS 10, Prisma 6, PostgreSQL 16
  - Frontend : React 18, Vite 6, TailwindCSS 3, shadcn/ui
  - Auth     : JWT (access + refresh), Argon2id
  - Monorepo : pnpm workspaces


2. FUNCTIONAL REQUIREMENTS
================================================================================

2.1 AUTHENTICATION (AUTH)
--------------------------------------------------------------------------------
  AUTH-01  [High]    User dang nhap bang email + password
  AUTH-02  [High]    He thong tra ve access token (15m) + refresh token (7d)
  AUTH-03  [High]    User doi mat khau (can xac nhan mat khau hien tai)
  AUTH-04  [High]    Refresh token de lay access token moi
  AUTH-05  [High]    Dang xuat -> xoa token khoi client
  AUTH-06  [Medium]  Register moi (chi ADMIN hoac public lan dau)
  AUTH-07  [High]    Mat khau hash bang Argon2id

2.2 USER MANAGEMENT (USER)
--------------------------------------------------------------------------------
  USER-01  [High]    ADMIN xem danh sach user (phan trang)

  USER-03  [High]    ADMIN cap nhat thong tin user
  USER-04  [High]    ADMIN khoa/mo khoa user (activate/deactivate)

  USER-06  [High]    User xem profile cua minh

  CLASS-04 [High]    TEACHER enroll hoc sinh vao class

  CURR-02  [High]    TEACHER tao chapter trong curriculum

2.7 SUBMISSIONS (SUB)
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

4. DATABASE SCHEMA OVERVIEW
================================================================================

4.1 DOMAINS
--------------------------------------------------------------------------------
  Identity    : User
  Academic    : Class, Enrollment
  Content     : Curriculum, Chapter, Lesson
  Assessment  : Question, QuestionOption, Assignment, AssignmentQuestion,
                AssignmentTarget
  Learning    : Submission, SubmissionAnswer, ProgressSnapshot,
                LearningSession, Feedback

4.2 KEY RELATIONSHIPS
--------------------------------------------------------------------------------
  User --< Class (teacher)
  User --< Enrollment (student) >-- Class
  Curriculum --< Chapter --< Lesson
  Lesson --< Assignment --< AssignmentQuestion >-- Question --< QuestionOption
  Assignment --< AssignmentTarget >-- Class | User
  AssignmentTarget --< Submission --< SubmissionAnswer
  Submission --< Feedback
  User --< ProgressSnapshot
  User --< LearningSession >-- AssignmentTarget

8. INSTALLATION
================================================================================

  Prerequisites:
    - Node.js >= 20
    - pnpm >= 9
    - Docker Desktop

  Steps:
    1. Copy .env.example to .env
       cp .env.example .env

    2. Start all services with Docker:
       docker compose up -d --build

    3. Or run development mode:
       pnpm install
       pnpm db:generate
       pnpm db:push
       pnpm db:seed
       pnpm dev

  Access:
    Frontend  : http://localhost:5173
    Backend   : http://localhost:3000
    Swagger   : http://localhost:3000/api/docs
    Adminer   : http://localhost:8080
